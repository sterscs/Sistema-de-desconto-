# 💰 Sistema de Desconto Progressivo

Programa em Python que calcula descontos progressivos em compras de uma loja online, de acordo com o valor total informado pelo cliente.

---

## 📋 Descrição

O sistema solicita ao usuário o valor total da compra e aplica automaticamente o desconto correspondente, seguindo as regras abaixo:

| Faixa de valor da compra        | Desconto aplicado |
|---------------------------------|-------------------|
| Menor que R$ 200,00             | 5%                |
| De R$ 200,00 até R$ 299,99      | 10%               |
| A partir de R$ 300,00           | 15%               |

Ao final, o programa exibe:
- O valor original da compra;
- O percentual de desconto aplicado;
- O valor do desconto em reais;
- O valor total a ser pago após o desconto.
